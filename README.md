# Финальное задание. 12 спринт — Работа над workflow

> **Примечание:** Папки `src/` (исходный код трекера посылок на Go) и `db/` (предустановленная база данных SQLite) предоставлены авторами курса в качестве исходных материалов задания. Моей задачей в рамках работы являлась настройка Docker-окружения.

## Структура проекта

```text
.
├── db/              # [Предоставлено заданием] Файл базы данных tracker.db
├── src/             # [Предоставлено заданием] Исходный код приложения на Go
├── docker/
│   └── Dockerfile   # [Моя работа] Оптимизированный Multi-stage Dockerfile
└── README.md        # [Моя работа] Документация к запуску
```

для локального теста надо скопировать db из ее папки временно в src


```bash
# Запускаем сборку из корня проекта
docker build -t learning-go-tracker:local -f docker/Dockerfile .
# Запуск контейнера
docker run -d -p 8080:8080 --name tracker-test learning-go-tracker:local
```
